# ADR-0002: 聴覚保護のため、出力段にピークリミッターと音量上限を置く

- 日付: 2026-11-13
- 状態: 採用

## 背景
聴覚過敏のプロファイルは 3〜4kHz を +15〜18dB 持ち上げる。マイクが急に大きな音（拍手・声）を拾うと、ヘッドホンから非常に大きな音が出て耳を傷める危険がある。
このアプリは聴覚の理解を目的としており、利用者・審査員の耳を傷めることは絶対に避けたい。

## 決定
- 出力段（EQ・リバーブの後）にピークリミッター（`kAudioUnitSubType_PeakLimiter`、`AVAudioUnitEffect` 経由）を置く
- ミキサーの出力音量に上限を設ける
- 開始時は 0 からフェードインする
- 上限値・ブースト量は定数（`FilterParameters` など）にまとめ、実機で聞いて決める

## 検討した他の案と捨てた理由
- 案A: ブースト量を下げるだけにする。捨てた理由: 体験としての「刺さる感じ」が弱くなる。しかもマイクが急に大きな音を拾えば、下げたブーストでも大きな音が出うる。根本対策にならない
- 案B: ユーザーに端末の音量調整を任せる。捨てた理由: 審査員は事前に音量を下げてくれるとは限らない。入力が急に大きくなる事故は音量設定では防げない

## 結果・影響
- 急な大音量から耳を守れる。説明可能な安全設計として、審査・面接でも話せる
- リミッターが働くと音が圧縮されるため、聴覚過敏の「刺さる感じ」が少し減る。ブースト量とリミッターのしきい値を実機で調整する
- 追加の処理ノードが入るが、負荷は小さい
