# HearingLens

Swift Student Challenge 提出用の iOS/iPadOS アプリ（Swift Playgrounds `.swiftpm` / SwiftUI）です。健常者がヘッドホンで ①高音難聴 ②低音難聴 ③APD（聴覚情報処理障害）④聴覚過敏 の「聞こえ方」をリアルタイムに疑似体験し、相手と話すときの配慮（対応術）を身につけることを目的としています。

## モード

- **日常モード**: 周囲の音にフィルタをかけて、聞こえ方を体験する
- **会話モード**: フィルタに加えて、話し方のアドバイス表示、声量メーター、対応術の実践スイッチを使って会話の練習をする

## 動かし方

1. `HearingLens.swiftpm` を Xcode または iPad の Swift Playgrounds で開く
2. マイクを使う体験は **必ずヘッドホンを着用して** 行う（ハウリング防止）
3. ヘッドホンがない場合は **テスト音源モード** を使う

## 注意

このアプリは理解のための近似的な体験であり、医学的な診断や症状の正確な再現ではありません。
