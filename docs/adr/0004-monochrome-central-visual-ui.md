# ADR-0004: 完全モノクロ・中央ビジュアル型のUI

- 日付: 2026-11-13
- 状態: 採用

## 背景
- 今の UI はプロファイルごとに4色を使い、カードを縦に並べた画面で、派手でまとまりがない
- 色で見分けるデザインは、色覚の多様性があると判別しづらい。聞こえ方の多様性を扱うアプリが、見え方の多様性を取りこぼすのは筋が悪い
- SSC の審査は短時間で、3分で核心体験に届く導線が必要
- SSC 規約により、アプリ内のコンテンツはすべて英語にする（design.md 1章）

## 決定
画面中央にビジュアル（波紋）を置く、完全モノクロの UI にする。

- **外観**: OS のライト/ダーク連動（アプリ内の切替なし）。基準はダーク
- **色**: 白・黒・グレー階調のみ。背景はダーク `#0E0E10`・ライト `#F5F5F3`、前景はダーク 白・ライト `#111111`。補足文字・線は前景の不透明度で段階をつける（補足文字もコントラスト比 4.5:1 以上）
- **選択・状態**: 色ではなく太さ・明るさ・形で示す（選択中タブ = semibold＋前景100%＋下に小さな点）
- **文字・アイコン**: システムフォント・Dynamic Type のテキストスタイルのみ。アイコンは SF Symbols でウェイト統一
- **動き**: 控えめ。Reduce Motion 時は波紋を静止
- **値の集約**: 色・余白などは `Theme.swift` に集約
- **S-02 の構成**: 上部バー（モード文字切替・ⓘ）／中央の波紋／プロファイル名＋shortDescription／会話モードのみアドバイス1つ＋Practice the tips／プロファイル文字タブ／状態1行／音量スライダー＋丸い主ボタン。詳しい解説・アドバイス3つ・Test Sound・オンボーディング再表示は ⓘ シートへ移す

## 検討した他の案と捨てた理由
- プロファイルごとの4色: 色覚によって判別しづらく、派手になる。捨てた
- モノクロ＋アクセント1色: 色がなくても状態を示せるので、色覚の影響がゼロで、さらに単純な完全モノクロを選んだ
- カードを縦に並べるスクロール画面: 情報が多すぎ、3分で核心体験に届く導線に向かない
- アプリ内のテーマ切替: シンプルさに反するため、OS 設定に連動する

## 結果・影響
- 画面が静かになり、体験（聞くこと）が中心になる。色に頼らないので色覚の多様性の影響を受けない
- 詳しい解説・アドバイス3つは ⓘ シートへ移り、メイン画面の情報量が減る
- テスト音源スイッチが ⓘ 内になり、ヘッドホンのない審査員が見つけるまで1手増える。状態1行で "turn on Test Sound in ⓘ" と案内して補う
- 色が使えないぶん、選択状態の見分けは太さ・点・不透明度に頼る。実機・Dynamic Type 最大・Reduce Motion で見え方を確認する
- 波紋が音量に反応する部分はフェーズ3。今回は `level` を受け取る口だけ用意する
