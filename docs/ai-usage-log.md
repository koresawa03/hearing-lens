# ai-usage-log.md — AI 利用の記録

## 目的
SSC 2027 では、AI ツールは特定の作業の補助として使えるが、使用をすべて開示する必要がある。本人の大きな貢献と技術的理解を示すことも求められる。
このファイルは、提出時の開示文を作るための記録である。提出フォームの作文は作者本人が書く（AI に書かせない）。

## 書き方
- 作業が完了するたびに、AI（Claude Code）が1行追記する。「作者が行ったこと」の欄は【要記入】のままにしておき、作者が自分の言葉で埋める。
- 列: 日付 / 機能ID / AIが行ったこと / 作者が行ったこと

## 注意
元の仕様書（`プロンプト.txt`）は作者が Gemini に書かせたもの。これも開示の対象になりうるので、作者は「作者が行ったこと」の欄でその旨を明記すること。
