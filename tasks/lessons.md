## 2026-11-17 — 積み重ねた PR が自動クローズされた
- 状況: PR #8 を PR #7 のブランチの上に積み重ねていた。PR #7 を `gh pr merge --delete-branch` でマージした結果、base のブランチが消え、PR #8 が自動でクローズされた（同じ内容で PR #9 を作り直してマージ）
- 原因: 下の PR のマージと同時にブランチを削除し、GitHub が上の PR の base を main に付け替える前に base が無くなった
- 次からのルール: 積み重ねた PR があるときは、下の PR を `--delete-branch` なしでマージ → 上の PR の base が main に変わったことを `gh pr view` で確認 → それから古いブランチを削除する
